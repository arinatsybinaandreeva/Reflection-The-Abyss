# 🎮 Reflection: The Abyss

**A psychological simulator about escaping depression.**

You wake up in a black hole. No energy. Your brain demands death. This is not you — this is the illness. Can you get out?

## 🧠 About the Game

This is not just a game. It's an interactive simulator based on **Cognitive Behavioral Therapy (CBT)** and the **neuroscience of depression**.

You play as a person going through 4 stages:
1. **Severe Depression** — survival
2. **Moderate Depression** — first steps
3. **Mild Depression** — returning to life
4. **Remission** — victory

## ⚙️ Mechanics

- **3 actions per day** (sleep, exercise, food, work, socializing, CBT journal, rest).
- **5 stats:** health, energy, reflection, calm, hunger.
- **Death from 4 causes:** depression, exhaustion, nervous breakdown, starvation.
- **CBT Journal:** 9000+ combinations of cognitive distortions.
- **Dialogs:** 52 situations × 3 reactions (assertiveness, passivity, aggression).
- **Work:** 80+ shift outcomes depending on your condition.

## 🚀 How to Run

1. Download `game.html`.
2. Open it in any browser (Chrome, Safari, Edge).
3. Play.

No installation, dependencies, or internet required.

## 🧪 Psychological Basis

The game is based on:
- Cognitive Behavioral Therapy (CBT)
- Neuroscience of depression (dopamine, serotonin, cortisol)
- Attachment theory
- Working with cognitive distortions

## ⚠️ Disclaimer

This is **not a replacement for therapy**. If you feel you can't cope — seek professional help.
